Snapback Trend Rider — a tiny long-only paper-trading bot for hourly Solana bars. It buys sharp dips that start turning up (close 2.5% under the 18-bar EMA and ticking higher), then sells on a 5% gain, a 2% loss, a 5% trailing stop, a broken trend, or after 24 bars. One 20%-of-equity position per symbol, never shorting, never leveraged. Fully deterministic: the same bars always produce the same orders. On the dev window it scored +$77.43 net PnL over 16 trades with an 87.5% win rate and 0.29% max drawdown.

## Run it

```sh
node main.ts
```
